# Prime Retail Group

Premium commercial real estate website for **Prime Retail Group** (Bakersfield / Kern County, CA)—an umbrella platform for retail brokerage, tenant representation, investment sales, development advisory, property management, and multi-venture holdings.

Original branding and copy. Inspired by institutional CRE site patterns, but **not** affiliated with Cushman & Wakefield or any national franchise. Do not reuse C&W logos, trademarks, or proprietary imagery.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Deployable on Vercel

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Design notes

- **Palette:** charcoal (`#1c1917`), warm cream (`#f7f3eb`), Bakersfield terracotta (`#c45c26`), restrained gold (`#b08d3a`) and sage green (`#5c6b4a`) accents
- **Typography:** Geist sans, generous whitespace, editorial split layouts
- **Mark:** custom `PRG` wordmark block—never a third-party logo
- **CTAs:** persistent *Schedule a Consultation* and *View Available Properties*
- Sample property photos from [Unsplash](https://unsplash.com) (commercial / retail / architecture). Credits noted on cards via `imageCredit` in `src/lib/site.ts`. Replace with owned photography for production.
